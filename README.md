SKILLON — адаптивный одностраничный сайт, подготовленный как быстрый frontend-концепт для лыжного спортивного мероприятия «Праздник Севера 2026».

## История проекта

Задача состояла в том, чтобы за очень короткий срок собрать презентационный сайт мероприятия: показать программу, формат участия, спортивные пакеты, информацию о поездке и блок регистрации. Первая версия была создана примерно **за половину рабочего дня**.

Продолжение разработки потеряло актуальность по внешней причине: **соревнования отменили из-за погодных условий — снег растаял**. Поэтому проект не доводился до полноценного коммерческого запуска и был заморожен в состоянии концепта. Сейчас он сохранён как архивный пример быстрой frontend-разработки, а не предлагается как действующая страница мероприятия.

> Даты, предложения и регистрационные элементы на макете исторические. Не используйте страницу для записи на мероприятие.

## Демонстрация

**Архивная демонстрация:** [https://skillon.kil-com.ru/](https://skillon.kil-com.ru/).

Статическая версия размещена в отдельной директории архивных проектов на основном VPS, обслуживается Nginx с HTTPS. Это исторический концепт: сведения о мероприятии и элементы регистрации не являются актуальным предложением.

## Что реализовано

- Адаптивный лендинг на React и TypeScript.
- Первый экран с SVG-горами, анимированным снегом и декоративными эффектами.
- Мобильная и десктопная навигация по секциям.
- Блоки о мероприятии, программе, пакетах, маршруте и регистрации.
- Интерактивные элементы и оформление в спортивной тематике.

## Стек

React 19 · TypeScript · Vite 7 · Tailwind CSS 4.

## Локальный запуск

Требуются Node.js и npm.

```bash
npm ci
npm run dev
```

Сборка и просмотр результата:

```bash
npm run build
npm run preview
```

Основная реализация: [src/App.tsx](src/App.tsx).


## Сборка

Для получения статической версии используйте `npm ci && npm run build`. Содержимое `dist/` генерируется локально и не хранится в Git.

**Архив / короткие концепты.** SKILLON показывает скорость подготовки тематического адаптивного интерфейса в условиях ограниченного времени. Он не входит в список активно развиваемых проектов и не позиционируется как работающая платформа соревнований.

### English summary

**SKILLON — archived winter sports landing-page concept.** An initial responsive React/TypeScript version was developed in approximately half a working day for a planned ski event. The competition was cancelled because changing weather conditions caused the snow to melt, so the website remained a concept. It is preserved as a rapid-implementation frontend sample, **not** an active event-registration website.
